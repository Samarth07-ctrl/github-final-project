# Simple Interest Calculator

A simple bash script that calculates simple interest based on the principal amount, annual rate of interest, and time period in years.

## Formula
$$\text{Simple Interest} = \frac{P \times R \times T}{100}$$

Where:
- **P** = Principal amount
- **R** = Annual interest rate (percentage)
- **T** = Time period in years

## Usage

1. Clone the repository:
   ```bash
   git clone https://github.com/Samarth07-ctrl/simple-interest-calculator.git
   cd simple-interest-calculator
   ```

2. Give execution permissions to the script:
   ```bash
   chmod +x simple-interest.sh
   ```

3. Run the script:
   ```bash
   ./simple-interest.sh
   ```

4. Enter the required inputs when prompted:
   - Principal amount
   - Annual interest rate
   - Time period in years

## Example
```text
Enter the principal:
1000
Enter rate of interest per year:
5
Enter time period in years:
2
The simple interest is:
100
```
